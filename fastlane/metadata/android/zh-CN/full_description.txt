ProCraft 是一款面向 Android 平板的开源绘画应用，专为用笔绘画而设计。它的绘画引擎与 GPU 渲染器以 Rust 从零编写，界面则使用 Kotlin 与 Jetpack Compose 构建。目前处于测试阶段。

<b>画笔</b>
<ul>
<li>画笔会跟随手写笔的压力与倾斜，由形状与颗粒构成，并具备防抖、笔锋、湿混色与颜色动态</li>
<li>内置多套画笔库，还有画笔工作室（Brush Studio），可修改任意画笔，也可自创新的画笔</li>
<li>可导入其他绘画软件的画笔文件（如 Krita、GIMP），并尽量接近它们原本的绘制效果</li>
</ul>

<b>图层与颜色</b>
<ul>
<li>图层支持混合模式、不透明度、Alpha 锁定、剪贴蒙版、蒙版与图层组，以及参考图层</li>
<li>色轮、经典、谐和与明度取色器，调色板、颜色历史与吸管；把颜色拖到画布上即可填充</li>
</ul>

<b>编辑</b>
<ul>
<li>多种调整，每项都有独立工具栏，可作用于整个图层，也可只涂抹在你需要的位置</li>
<li>选区（自动、手绘、形状、羽化）与变换（自由、等比、扭曲、网格变形，支持吸附）</li>
<li>笔画结束时按住笔，形状会自动对齐；还有绘图参考线与绘图辅助（2D 网格、等距、透视、对称），以及文本</li>
</ul>

<b>更多</b>
<ul>
<li>动画与分镜辅助，以及参考窗口</li>
<li>在 OBJ 与 USDZ 模型上进行 3D 绘画，支持灯光与环境</li>
<li>带作品堆栈与画布预设的画廊；可导入并分享 PNG、JPEG、PSD、PDF、TIFF、GIF 与 MP4；每幅作品都有延时视频</li>
<li>可选插件，默认关闭，需在“偏好设置 › 插件”中开启，且运行于沙盒之中</li>
</ul>

ProCraft 没有广告、没有追踪，也不接入互联网：应用不申请网络权限。它面向平板；手机将另有一款独立应用。
